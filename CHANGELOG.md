# Чейнджлог

Пишется для человека, который пользуется программой, а не для того, кто читает код.
Раздел версии становится описанием релиза.

Тег `vX.Y.Z` ставится только на раздел **с датой**. Пока правки лежат под
«Не выпущено», релиза не будет — это предохранитель от случайного выпуска
недоделанного.
