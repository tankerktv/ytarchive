# Установка ytarchive

Для того, кто ставит программу впервые. Путь от пустой машины до первой
скачанной серии — шесть шагов, минут пятнадцать, из которых десять качается
само.

*English version: [INSTALL.md](INSTALL.md).*

## Коротко

1. Поставить Python 3.10 или новее.
2. Скачать программу.
3. Запустить установщик: `install.cmd` на Windows, `./install.sh` на Linux и macOS.
4. Поставить `node` и `ffmpeg`, если установщик сказал, что их нет.
5. Положить куки YouTube.
6. Открыть окно, добавить канал, нажать «Запустить».

Дальше — то же самое подробно.

## Шаг 1. Python

Нужен Python **3.10 или новее**. Проверить, что уже есть:

```bash
python --version
```

На Linux и macOS команда может называться `python3`.

Если Python нет или он старше:

| Система | Как поставить |
|---|---|
| Windows | `winget install Python.Python.3.12` — или установщик с [python.org](https://www.python.org/downloads/); в нём **отметьте «Add python.exe to PATH»** |
| macOS | `brew install python` — или установщик с python.org |
| Debian, Ubuntu | `sudo apt-get install python3 python3-venv` |
| Fedora | `sudo dnf install python3` |

На Debian и Ubuntu пакет `python3-venv` нужен отдельно: без него установщик
остановится на первом же шаге и сам об этом скажет.

## Шаг 2. Скачать программу

Проще всего — архивом: на странице
[github.com/tankerktv/ytarchive](https://github.com/tankerktv/ytarchive)
кнопка **Code → Download ZIP**. Распакуйте туда, где программа будет жить.

Или через git — так потом проще обновляться:

```bash
git clone https://github.com/tankerktv/ytarchive.git
```

**Выберите место сразу.** Программа ставится в свою же папку, и ярлыки
указывают на неё. Перенесёте папку — запустите установщик ещё раз.

Не кладите программу в папку, которая синхронизируется в облако: окружение
Python внутри неё — это тысячи мелких файлов.

## Шаг 3. Установщик

**Windows:** дважды щёлкните `install.cmd`.

Если Windows покажет «Система Windows защитила ваш компьютер» — это реакция
на файл, скачанный из интернета. «Подробнее» → «Выполнить в любом случае».
Что файл делает, видно в нём самом: он находит Python и запускает
`install.py`.

**Linux и macOS:** в терминале, из папки программы:

```bash
./install.sh
```

Установщик:

1. спросит, класть ли ярлык и запускать ли выкачку при входе в систему;
2. покажет список того, что собирается сделать;
3. спросит «Выполнить?» — и только после согласия что-то тронет.

Отвечать можно по-русски (`д`, `н`) или по-английски (`y`, `n`). Пустой
ответ — согласие с тем, что предложено заглавной буквой.

### Что именно он делает

| Что | Куда |
|---|---|
| Окружение Python | `.venv` в папке программы |
| Пакеты: `yt-dlp`, окно (PySide6) | в это окружение, не в систему |
| Ярлык «Архив YouTube» | Windows — рабочий стол; Linux — меню приложений; macOS — рабочий стол |
| Автозапуск выкачки | Windows — папка «Автозагрузка»; Linux — `~/.config/autostart`; macOS — `~/Library/LaunchAgents` |

Прав администратора не просит и `sudo` не запускает. За пределами папки
программы появляются только ярлык и запись автозапуска.

### Посмотреть, ничего не меняя

```bash
python install.py --dry-run
```

### Ключи

| Ключ | Что делает |
|---|---|
| `--dry-run` | только показать шаги |
| `--yes` | не задавать вопросов |
| `--no-gui` | без окна: командная строка и фоновая выкачка (не ставит PySide6) |
| `--no-shortcut` | не класть ярлык |
| `--no-autostart` | не запускать выкачку при входе в систему |

На Windows ключи передаются так: `install.cmd --no-autostart`.

## Шаг 4. node и ffmpeg

Эти две программы через Python не ставятся. Установщик проверит, есть ли
они, и:

* на Windows и macOS — предложит поставить сам (через `winget` или `brew`);
* на Linux — напишет команду, которую нужно выполнить вам: она требует
  `sudo`, а пароль администратора установщик не спрашивает.

| Программа | Зачем | Windows | macOS | Debian, Ubuntu |
|---|---|---|---|---|
| `node` | без него YouTube отдаёт раскадровку вместо ролика | `winget install OpenJS.NodeJS.LTS` | `brew install node` | `sudo apt-get install nodejs` |
| `ffmpeg` | видео и звук приходят порознь, склеивать нечем | `winget install Gyan.FFmpeg` | `brew install ffmpeg` | `sudo apt-get install ffmpeg` |

После установки **откройте новый терминал** (на Windows надёжнее выйти из
системы и войти снова): уже открытые окна новых программ не увидят.

## Шаг 5. Первый запуск и куки

Откройте окно — ярлыком «Архив YouTube» или командой:

```bash
.venv/bin/python ytarchive.py gui              # Linux, macOS
.venv\Scripts\pythonw.exe ytarchive.py gui     # Windows
```

В первый раз программа спросит **язык** и **папку для архива** — туда будут
складываться ролики, по папке на канал. Берите диск с запасом: один канал —
это легко сотни гигабайт.

### Куки

YouTube не отдаёт ролики тому, кто не вошёл в аккаунт. Программе нужен файл
с вашей сессией — `cookies.txt`:

1. Откройте в браузере **приватное окно** (инкогнито) и войдите в YouTube.
2. В этой же вкладке откройте `https://www.youtube.com/robots.txt`.
3. Выгрузите куки для `youtube.com` расширением, которое сохраняет их в
   формате Netscape, — например «Get cookies.txt LOCALLY».
4. **Закройте приватное окно**, больше им не пользуясь.
5. Положите файл как `_tools/cookies.txt` в папке архива (папку `_tools`
   создайте, если её ещё нет).

Приватное окно здесь не из осторожности: YouTube регулярно меняет куки
открытой вкладки, и выгруженные из обычного окна быстро перестают работать.

> **Этот файл — ваш вход в аккаунт Google, открытым текстом.** Кто его
> прочитал, тот вошёл как вы. Не кладите его в общие папки, облако и
> резервные копии, которые читает кто-то ещё. Спокойнее всего завести для
> архива отдельный аккаунт.

**Или без файла.** В настройках окна есть поле «Куки YouTube»: выберите
там браузер, в котором вы вошли в YouTube, и программа возьмёт куки прямо
из него. Из Firefox это работает надёжно. Chrome и Edge на Windows куки
шифруют, и прочитать их часто не удаётся — тогда остаётся файл.

Когда куки истекут, программа скажет это словами — «истекли куки» — и будет
ждать, а не перебирать каналы впустую. Если окно запущено, оно скажет об этом ещё и всплывающим сообщением из трея.
Лечится повторением этих пяти шагов.

### Проверить, что всё на месте

```bash
.venv/bin/python ytarchive.py check            # Linux, macOS
.venv\Scripts\python.exe ytarchive.py check    # Windows
```

`check` называет словами, чего не хватает — `node`, `ffmpeg`, куки, — и
ничего не качает. Работает после первого запуска: до него нет настроек.

## Шаг 6. Первый канал

1. Вкладка **«Каналы»** — найдите канал по названию. Ещё до добавления видно,
   сколько в нём роликов и сколько места они займут.
2. Добавьте канал. Если нужны не все ролики — откройте их список и снимите
   лишние галочки, или задайте кнопкой «Правила…» отбор сразу: не короче,
   не длиннее, не старше.
   Плейлист или отдельный ролик добавляются кнопкой «Добавить по адресу…».
3. Вкладка **«Обзор»** → **«Запустить»**.

Окно можно закрыть — оно спрячется в трей, выкачка продолжится. Дальше
программа сама проверяет каналы: раз в полчаса, если нового нет.

Посмотреть заранее, что и сколько будет скачано, ничего не качая:

```bash
.venv/bin/python ytarchive.py plan
```

## Обновление

Скачайте новую версию поверх старой (или `git pull`) и запустите установщик
ещё раз. Настройки и архив он не трогает.

Установщик стоит запускать и без новой версии — раз в месяц-два или когда
программа скажет «yt-dlp устарел»: он обновляет `yt-dlp`, а тот стареет
быстро, потому что YouTube меняется постоянно.

```bash
python install.py --yes
```

То же делает кнопка «Обновить yt-dlp» в настройках окна и команда
`ytarchive.py update`.

Программа работает со своим `yt-dlp` — тем, что установщик положил в её
окружение, — даже если в системе стоит другой. Тот остаётся вашим: программа
его не трогает и не обновляет.

## Удаление

1. Остановите выкачку: кнопкой в окне или `ytarchive.py stop`.
2. Удалите ярлык и запись автозапуска (где они — в таблице шага 3).
3. Удалите папку программы.

Архив с роликами лежит отдельно, и удаление программы его не касается.

## Если что-то не так

| Что видно | В чём дело |
|---|---|
| `install.cmd`: «Python 3.10 or newer was not found» | Python не установлен или не попал в PATH — шаг 1; после установки откройте файл заново |
| Установщик остановился на создании окружения (Linux) | нет пакета `python3-venv` — `sudo apt-get install python3-venv` |
| Остановился на установке пакетов | обычно нет сети или мешает прокси; запустите ещё раз — сделанное сохранится |
| «не получилось: положить ярлык окна» | на Windows с жёсткой политикой безопасности создание ярлыков сценарием запрещено; сделайте ярлык руками на `.venv\Scripts\pythonw.exe` с параметрами `ytarchive.py gui` |
| `check` говорит «нет node» сразу после его установки | терминал открыт до установки — откройте новый |
| Качаются картинки-раскадровки вместо роликов | нет `node` |
| «истекли куки» | шаг 5, куки заново |
| «yt-dlp устарел» | кнопка «Обновить yt-dlp» в настройках или установщик ещё раз |
| В журнале «идёт медленнее … — откладываю» на каждом ролике | линия медленнее порога; в настройках окна поставьте «Откладывать загрузку медленнее» в «не проверять» |
| Окно не открывается, в терминале «окно требует PySide6» | ставили с `--no-gui`; запустите установщик без этого ключа |

## Без установщика

Установщик не делает ничего, чего нельзя сделать руками:

```bash
python -m venv .venv
.venv/bin/python -m pip install ".[gui]" "yt-dlp[default]"
.venv/bin/python ytarchive.py gui
```

На Windows вместо `.venv/bin/python` — `.venv\Scripts\python.exe`.

## Что проверено

Установщик проверен на Windows 11 и на Debian. **На macOS не проверялся**:
шаги для него написаны по документации, и оснований ожидать, что они
сработают, достаточно — но ожидание это не проверка. Если что-то пошло не
так, `--dry-run` покажет, на каком шаге, а раздел «Без установщика» проведёт
в обход.
